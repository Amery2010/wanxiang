## 美术与目录口径

3,730 是登记条目数，不是 3,730 套完全独立成品。基础件、功能子装配、完整资产和场景分层复用。当前新增 120 个 L1 部件和 10 个 L2 组合样例；不将风格、配色、尺寸或细节参数复制计数。题材清单按几何族实现，不意味着每一种动物、车辆或职业都有独立完整成品。

视觉证据来自实际导出 GLB 的 CPU 正交渲染／浏览器 CPU 回退。程序审查不是用户批准，也不是客观“审美满分”。CPU 渲染近似顶点色与材质因子、光照和阴影，不模拟完整 GPU 金属反射、透明折射或全局光照。

## 设备与格式

实体 GPU、Safari、iOS／Android 硬件和 FPS 未验证。浏览器小屏截图仅验证布局。环境允许的页面加载方式与实际渲染后端记录在浏览器报告中；受限情况下加载交付 HTML 精确字节，不把它当作真实 file/HTTP 导航成功。未运行官方 Khronos glTF-Validator，不将内部检测、trimesh 和 GLTFLoader 回读称为官方认证。

通用 GLB 保留核心 PBR 回退；自定义 Toon 光照分阶需要目标引擎显式支持。网页和 Python 动画、骨架与变换有契约测试，但不是外部引擎全部功能认证。

## 集成边界

门、平台、机器人具有真实关节和有限动画，不含 IK、碰撞反馈、脚底锁定、步态控制或行为 AI。人物复用骨架，装备主要为有意设计的刚性骨骼挂装，不含布料或毛发模拟。蛇与触手提供分段蒙皮，不是通用生物运动求解器。

碰撞元数据、触发区、事件、碎片和 FX 挂点需目标游戏消费。没有内置战斗逻辑、自动发射粒子、可玩关卡、NavMesh、地形流送、浮力或铁路行车调度。FX 代理不把大量粒子烘焙进 GLB；部分爆炸对象的碎片由消费端生成。管道保留可见内腔和精确端部，但 T 接头不宣称做过流体连通 CSG／制造级实体布尔。

LOD 声明不等于实际简化：当前回归中，部分资产在 level 0 / 1 下导出相同面数，例如 `l1.terrain.surface.dried` 和 `l3-architecture-building-apartment`。使用前须核对实际导出的几何差异；不宣称全库 LOD 有效。碰撞层、动态凹体限制、胶囊非均匀缩放和自动 LOD 切换距离由引擎处理。`assembly_colliders` 的 `replace-children` 必须避免与重复子碰撞叠加；未声明的旧资产不自动生成阻挡包围盒。

## 缓存和发布

受控空白来源下无法证明 IndexedDB 跨浏览器重启持久化；内存缓存、损坏检测、配额失败和 Worker 禁用回退有实际测试。缓存上限不包含渲染器、当前场景与构建／导出临时数据，不是总内存保证。

浏览器导出报告只确认发起下载；验收工具保存实际下载文件并回读后删除，不把它们留在源码中。CLI changed-only 校验已有磁盘文件的哈希。ZIP 冷解压、CRC、封闭哈希和字节一致重建验证实际交付包，不等于替用户客户端验证下载服务。

源码不含 Python/Node 解释器、依赖 wheels、浏览器安装包、字体二进制或 npm 缓存。首次开发环境安装可能需要网络，内嵌 HTML 使用时不需要外部请求。正式 CLI 默认严格持久化；测试读回策略不是断电容灾认证。
