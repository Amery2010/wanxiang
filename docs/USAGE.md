# 使用指南

按 README 安装依赖后，在仓库根目录运行 `pnpm dev`，打开终端显示的本地地址，选择需要的 L1–L4 层级或游戏扩展目录。主题和层级筛选可叠加；“shared”是跨主题部件，不是额外主题。当前对象的几何、材料、BOM 和作者源可以逐一查看。

“参数”提交结构重建；“运动状态”在有效范围内更新节点。射线验证过的船舱、压力舱门洞与气闸不是黑色贴片。骨架角色、悬浮车辆和机器人不附带自动游戏操控、碰撞或IK。

标准／中性灰／夜景只改变展示。爆炸、线框、隔离和播放姿态也不是作者数据；正常导出从未污染的快照获得GLB。当前刚性状态导出只把该姿态固化为静态GLB。质量页运行时ZIP是独立优化副本，详见 `RUNTIME_EXPORT.md`。

外部GLB支持查看、动画、重导出，不虚构结构参数。它保留IMPORTED标识，不自动获得本库的审查结论。批量选择有内存与数量预算，不能无限载入所有大型场景。

源码开发依赖与命令见根目录中英文 README；浏览器本身不需要 Python 或 Node。遇到浏览器本地文件策略，可使用项目已有的本机启动入口。浏览器记录只代表实际运行环境，不能冒充移动真机、实体 GPU 或目标游戏兼容认证。
