# 显式接缝编译契约

## 适用对象

此算法用于参数化作者模型中**已经设计成对应接口**的相邻放样截面。它不是任意导入模型修复、体素布尔、SDF 全身融合或可打印性保证。肩部与分叉躯干等不是两个一一对应端环的连接，仍由作者轮廓和覆盖设计处理。

## 编译顺序

1. 展开语义参数、组件、骨架映射与继承材质，复制源定义，不原地改写作者数据。
2. 收集 `join_start` / `join_end` 的显式组，解析真实世界空间轮廓和蒙皮权重。
3. 同组必须恰有两个兼容的端环；枚举循环起点及反向排列，以最小平方距离配对。顶点数量不一致、超过允许距离或多端歧义时拒绝。
4. 在容差内将两端点取共享位置；每对权重取并集、保留最多四个主要骨骼权重并归一化。输出共享位置和权重而不改变其他顶点。
5. 仅成功配对的端环移除内部盖面；独立端环保持封闭。局部接缝法线仅在角度阈值内平均，不传播到整件硬表面。
6. 输出接缝诊断：组 ID、端环点数、输入与输出最大间距、共享权重标记和移除盖面数量。

默认作者连接容差为 0.055 米，法线阈值 32°，不是允许所有零件相差 5.5 厘米的建模规范。它们是拒绝错误输入的上限；合格接口应尽量从设计上匹配。参数极值检查会验证输出连接点重合。

## 当前接入

`core.human.body` 中双肘、双腕与双膝共六组端环已使用契约。手臂、手、腿继续绑定同一套骨架；接缝对应点的蒙皮权重一致，动作变形不会因为两份不同权重主动拉开这一端环。它不保证所有动作中手臂与衣服完全不穿插，也不保证整身是单一流形拓扑。

肩袖通过作者截面减小平盖、细化衣装过渡，不冒充已经自动焊接的分叉拓扑。马和新牲畜的毛色切换在现有网格面上着色；不再用一层白色或棕色薄壳叠在腿部或躯干表面制造花纹。

## 硬表面与运动

门扇、抽屉、轮胎、机械臂、活塞杆、围栏等不自动加入有机连接。它们保留真实铰链、缝隙、节点与材料分区。角度控制以度声明；直线行程以米声明。Python 与 JavaScript 对同一约束产生的节点矩阵进行回归比对。

## 可复现检查

```sh
node tools/seam_contract.cjs
python -m pytest tests/test_geometry.py tests/test_game410.py -q
```

JS 合同检查覆盖源定义不变、位置与权重一致、正确移除盖面、独立端环、反向配准，以及远距离／不等点数／三端歧义的拒绝。人体检查覆盖身高与体格范围的组合；该证据不应外推成全库任意接缝都已经处理。
